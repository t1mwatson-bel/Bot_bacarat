# 🤖 ML Baccarat Bot v3.0 — Самообучающийся ИИ

Бот сам находит стратегии, разрабатывает уникальные догоны и учится на своих ошибках.

## 🧠 Как работает
- Первые 500 игр — исследование (рандомные прогнозы)
- Затем анализ паттернов и создание гипотез
- Постоянная оптимизация и самообучение

## 🚀 Установка
1. Клонируй репозиторий
2. Создай файл `.env` (см. `.env.example`)
3. Установи зависимости: `pip install -r requirements.txt`
4. Запусти: `python main.py`

## 📊 Статистика
Бот ведёт полную статистику всех стратегий и прогнозов.
